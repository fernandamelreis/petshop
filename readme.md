# 🐾 Pet Feliz — Site de Pet Shop

## 📌 Sobre o projeto

O **Pet Feliz** é um projeto de desenvolvimento web que apresenta uma página institucional de um Pet Shop fictício, desenvolvido utilizando **HTML5 e CSS3**.

O objetivo é aplicar conhecimentos fundamentais de desenvolvimento Front-end, explorando a estruturação de páginas HTML, estilização com CSS e organização de conteúdos para a web.

## 🖥️ Funcionalidades

- 🏠 **Início:** apresentação do Pet Shop.
- 🐶 **Sobre nós:** informações sobre a empresa e sua missão.
- 🛁 **Serviços:** apresentação dos serviços de banho, tosa e acessórios.
- 📞 **Contato:** informações para comunicação com o estabelecimento.
- 🎨 **Estilização:** personalização de cores, fontes e espaçamentos.
- 🔗 **Navegação:** menu com links para as seções da página.

## 🚀 Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, cores, layouts e efeitos visuais.
- **Visual Studio Code:** ambiente de desenvolvimento.
- **Git e GitHub:** versionamento e hospedagem do código-fonte.

## ⚙️ Como executar o projeto

**1.** Faça o download do projeto ou clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

**2.** Abra a pasta do projeto no Visual Studio Code.

**3.** Localize o arquivo `index.html`.

**4.** Abra o arquivo diretamente no navegador ou utilize a extensão Live Server do VS Code.

Não é necessário instalar bibliotecas ou dependências adicionais.

## 🎯 Objetivos de aprendizagem

Este projeto permite desenvolver habilidades relacionadas a:

- Utilização de tags semânticas do HTML5.
- Organização de páginas web em seções.
- Criação de menus de navegação.
- Inserção de imagens e links.
- Aplicação de seletores, classes e IDs no CSS.
- Utilização do Flexbox para organizar elementos.
- Personalização visual de páginas web.
- Organização de arquivos em projetos Front-end.
- Introdução ao versionamento de código com Git e GitHub.
